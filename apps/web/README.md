# apps/web

SvelteKit PWA (TypeScript). Capture, check-ins, nudges, weekly review view. Offline-first
audio capture via IndexedDB with background sync to the API.

Local env: create `apps/web/.env` with `PUBLIC_API_URL=http://localhost:8787`
if the API is not on the default port.

Not yet scaffolded. See `../../docs/codebase-design.md`.
